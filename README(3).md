# Aprendendo C 🖥️

Repositório criado para documentar minha evolução aprendendo a linguagem **C** ao longo deste semestre.

## 🎯 Objetivo

Registrar meu progresso, praticando os conceitos da linguagem C através de exercícios, desafios e pequenos projetos, desde os fundamentos até tópicos mais avançados.

## 👨‍💻 Sobre mim

Sou estudante de Engenharia de Software na PUC Campinas. Já tenho conhecimento básico em Python e MySQL, e venho estudando Java por conta própria — agora é a vez do C!

## 📂 Estrutura do repositório

```
├── 01-fundamentos/       # Variáveis, tipos de dados, operadores, entrada/saída
├── 02-estruturas-controle/  # If/else, switch, loops (for, while, do-while)
├── 03-funcoes/           # Funções, escopo, recursão
├── 04-vetores-strings/   # Arrays, matrizes, manipulação de strings
├── 05-ponteiros/         # Ponteiros e alocação de memória
├── 06-structs/           # Structs, unions, typedef
├── 07-arquivos/          # Manipulação de arquivos
└── projetos/             # Projetos maiores que integram vários conceitos
```

> A estrutura pode ser ajustada conforme o conteúdo avançar ao longo do semestre.

## 🚀 Como compilar e rodar

Clone o repositório:

```bash
git clone https://github.com/arthursouzagimenes-dev/Aprendizado_em_C.git
cd Aprendizado_em_C
```

Os códigos são compilados com `gcc`. Exemplo:

```bash
gcc caminho/do/arquivo.c -o programa
./programa
```
